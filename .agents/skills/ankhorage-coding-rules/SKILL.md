# Ankhorage Coding Rules

Work on a task branch, preserve unrelated changes, and keep one canonical implementation. Every
production function has concise documentation. Test observable behavior at its owning boundary with
deterministic units before broader checks. Public symbols must be exported only through declared
entrypoints; never import sibling source. Report every validation command and failure accurately.
